# Engineering and product status

This file is a current index, not an independent certification. The detailed, dated [engineering status](ENGINEERING_STATUS.md) and [full audit](FULL_AUDIT_2026-10-07.md) carry the verification evidence. The [product direction](PRODUCT_DIRECTION.md) owns the customer thesis, product requirements and acceptance gates.

Line is a protocol prototype testing issuer-authorized agent purchasing. The repository contains a generated-Compact local checkout, deterministic local services, issuer/agent/merchant consoles, public accounting views, a network adapter and a twelve-circuit Compact contract. Local execution, tests and UI do not establish a live proof, finalized network lifecycle, asset backing, customer demand, full-history privacy or payout.

Current Compact source and managed artifacts must be checked with `npm run compact:compile` and `npm run compact:check`. Current test, browser, build, release and security-scanner results are recorded with timestamps in the evidence documents; older counts in archived Wave 2 documents describe their original snapshots only.

The initial buyer hypothesis is enterprise API/data/compute procurement, with no customer interviews, signed pilot or revenue established. The full destination remains private revolving credit and checkout for autonomous agent fleets. All product acceptance gates remain in scope; see the evidence table in [PRODUCT_DIRECTION.md](PRODUCT_DIRECTION.md).
