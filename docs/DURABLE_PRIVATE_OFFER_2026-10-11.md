A process test verifies that reopening with the enrollment profile fails, then reopening with the correct profile restores identity and its committed approval. Existing enrollment owners retain their default profile.

Fresh compiled execution passes six calls: funding, agent consent, issuer acceptance, supplier quote, agent draw and supplier redemption. Two actual child restarts preserve the agent's public key and exact consent/draw approvals. Four owner-policy denials stop foreign identity, merchant, domain and excessive price before Compact.
